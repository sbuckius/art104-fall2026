Colophon

File layout. Each session has a folder. Inside it, one file per person: week-01/artist_1.html through week-01/artist_24.html, plus artist_1.pdf and artist_1.txt alongside. The final session lives in final/. Files are exported straight out of The Comet and committed as they are.

To put real names on the buttons, edit the STUDENTS list at the top of this file's script. Filenames never change, so nothing breaks when a name is added, corrected, or removed. Leave an entry empty and the button shows its number alone.

To change a session, edit the SESSIONS list in the same place.

Set in Anton, Space Mono, and Permanent Marker. Overprinted in fluorescent pink, process blue, chrome yellow, and green, the way a two-pass riso never quite lines up. Hosted on GitHub Pages. No trackers, no analytics, no cookies.
