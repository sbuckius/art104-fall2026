    The SPECULATE ladder

    The sixth question needs a shape or it turns into freewriting. Four rungs, the same every week. This week you owe only rungs 1 and 2. Rung 3 arrives in Week 5, rung 4 once the strategies list is introduced.

    1. Name the object. One thing, ordinary, that fits in a hand or a room. Not a system, not an app, not a policy. If it cannot be photographed, it is not an object yet.
    2. Site it. Where is it, who made it, what did it cost, what did it replace? An object with no supply chain is a logo.
    3. Hand it over. Give the same object to somebody in a different place or position and say what breaks. From Week 5.
    4. Name the strategy. Which of the fourteen? If you cannot say, you have a mood, not a project. Later in the term.
